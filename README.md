# Plataforma de Pedidos de Comida

## Descripción

La Plataforma de Pedidos de Comida es un sistema diseñado para facilitar la consulta de menús, selección de productos y gestión de pedidos.

## Objetivo

El objetivo del sistema es organizar y facilitar el proceso de pedidos de comida, permitiendo una mejor gestión de la información de clientes, productos y pedidos.

## Problema que resuelve

El sistema busca reducir la dependencia de procesos manuales y facilitar la gestión de los pedidos entre clientes, administradores y repartidores.

## Funcionalidades principales

- Registro de usuarios.
- Inicio de sesión.
- Consulta del menú.
- Realización de pedidos.
- Consulta del estado del pedido.
- Gestión de productos.
- Gestión de pedidos.
- Actualización del estado del pedido.

## Arquitectura

El sistema se organiza mediante una arquitectura por capas, separando las responsabilidades de la interfaz, la lógica del sistema y la gestión de los datos.

### Frontend

El frontend será responsable de la interfaz que utilizarán los usuarios para consultar productos, realizar pedidos y consultar el estado de sus órdenes.

### Backend

El backend será responsable de procesar las solicitudes, aplicar las reglas del sistema y gestionar la información almacenada.

### Comunicación entre Frontend y Backend

El frontend se comunicará con el backend mediante una API. El backend procesará las solicitudes y devolverá la información necesaria para que el frontend pueda mostrar los resultados al usuario.
